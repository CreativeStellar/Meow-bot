## Setup

1. Install dependencies:

   pip install -r requirements
2. Copy .env.example to .env and add your Discord bot token:
   "DISCORD_TOKEN=your_bot_token_here"
   
4. Run:
   python bot.py

## Usage

- @mention the bot → 70% chance of cat text, 30% chance of cat picture
- .meow → Get a random cat response
- .catpic → Get a random cat picture

## Requirements

- Python 3.8+
- discord.py
- aiohttp
